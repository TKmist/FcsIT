User guide¶

The software consists of three modules listed below, which allow processing of FCS data. Follow the link to learn more about the modules.

  • Import PTU

  • Time-binned correlation

  • FCS fitting

By default, the FcsIT starts up in the FCS fitting mode. The other modules can be selected from the Methods menu; see image below.
